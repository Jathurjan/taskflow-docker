# TaskFlow – Docker & DevOps Practice

This project was built as a hands-on learning project to understand Docker and DevOps fundamentals.

### Technologies Used
- React.js
- Node.js & Express.js
- MongoDB
- Docker
- Docker Compose
- Nginx

### What I Practiced
- Creating Dockerfiles for frontend and backend
- Building Docker images
- Running containers
- Docker port mapping
- Docker volumes for persistent data
- Docker networking
- Connecting multiple containers
- Using Docker Compose to manage multiple services

### Run the Project

```bash
docker compose up -d --build
```

Frontend: http://localhost:3000

Backend: http://localhost:5000/api/health

**Purpose:** Learning and practicing Docker and DevOps concepts through a real-world MERN application.
